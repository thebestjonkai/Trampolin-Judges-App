# Kari — User Guide

*Deutsche Fassung: [ANLEITUNG.md](ANLEITUNG.md)*

This guide explains how to use the app. You do not need to know anything about
the code. The app is in English; this guide uses the button labels exactly as
they appear on screen.

---

## 1. Unlocking

The app opens on a lock screen with a single password field.

1. Tap the field — on a tablet the keyboard appears by itself.
2. Type the password.
3. Tap **Unlock**, or press Enter.

If the password is wrong, *Wrong password* appears in red and the text you typed
is selected, so you can simply type over it.

The password is the same for everyone and does not change. If you do not have
it, ask whoever set up the device.

---

## 2. The start screen

Two options:

* **Start Routine** — begin recording a new routine.
* **Library** — open the table with everything recorded so far.

---

## 3. Recording a routine

You will see six large buttons, **0** to **5**, and a dark red **10** at the
bottom left next to **Finish Routine**.

The colours tell you the range at a glance: 0 and 1 are green, 2 and 3 yellow,
4 and 5 red, the 10 dark red.

**Tap one button per element, in order.** The first tap fills `S1`, the second
`S2`, and so on up to `S10`; the eleventh tap fills `L` for the landing.

A heading above the buttons names the value your next tap records: *Judging
1st Skill*, *Judging 2nd Skill*, and so on up to *Judging Landing*. Once all
eleven are in, it reads *Routine complete*. **Finish Routine** counts along in
the same way — *Finish Routine after 3 Skills* — and drops the count once the
routine is full.

A routine holds **11 values**. Once all eleven are recorded, the buttons turn
pale and stop responding — that is the signal that the routine is complete.

When you are done, tap **Finish Routine**. The routine appears in the library.
**Finish Routine** can also be tapped earlier, for instance when a routine was
broken off.

> **There is no undo while recording.** A wrong tap is corrected afterwards in
> the library, where every value can be typed over. See section 5.

---

## 4. Reading the table

Each row is one routine, oldest at the top. The columns are:

| Column | Meaning |
| --- | --- |
| **S1**–**S10** | the ten elements, in the order you tapped them |
| **L** | the dismount and landing |
| **Total** | all values of that row added up |
| **E:** | the finished execution score of one judge |

**Total** and **E:** are calculated for you and update themselves.

The values keep their colours from the buttons, so a routine can be read at a
glance. A number that the buttons cannot produce — anything other than 0–5 and
10, for example a hand-typed 7 — is shown in plain white.

The routine you have just finished sits at the bottom with a bar on its left
edge, marking it as not yet saved. The heading and the column titles stay
visible while you scroll through a long list.

---

## 5. Correcting a value or entering a routine by hand

**Every cell in the table can be typed into.**

To correct a value: tap the cell, type the new number. The old one is replaced,
the colour adjusts, and **Total** and **E:** recalculate immediately. The row
you are working on is highlighted.

To enter a whole routine by hand: tap **Add Routine**. An empty row is added at
the bottom and the cursor lands in its first cell. Fill in the values.

Handy while typing:

| Key | Effect |
| --- | --- |
| **Enter** | next cell |
| **Shift + Enter** | previous cell |
| **↑ / ↓** | same column, one routine up or down |
| **Tab** | next cell |

Any whole number up to three digits is accepted — you are not limited to the
values on the buttons. Cells may also be left empty; an empty cell counts as 0
in **Total**.

Everything is saved the moment you type it. There is no save button.

---

## 6. The buttons in the library

| Button | What happens |
| --- | --- |
| **Lock** | Returns to the lock screen. **Nothing is deleted.** Asks for confirmation first. |
| **Reset** | **Deletes all routines** and returns to the start screen. Asks for confirmation first. |
| **Add Routine** | Adds an empty routine at the bottom for typing in by hand. |
| **Next Routine** | Keeps the current routine and goes straight on to the next recording. |
| **Delete last Routine** | Removes the routine saved most recently. Greyed out when there is nothing to delete. |

Two things that are easy to get wrong:

* **Next Routine** is the normal way onward. It saves what you just recorded and
  takes you straight back to the buttons — you do not go via the start screen.
* **Delete last Routine** deletes the last *saved* routine. If you arrived
  through **Finish Routine**, the bottom row is not yet saved, so the row above
  it is the one that disappears.

---

## 7. Where the data is kept

Routines are stored **on this device, in this browser**. They survive closing
and reopening the app.

They are **not** synchronised, **not** backed up, and not visible on any other
device. If you need the numbers elsewhere, write them down or take a screenshot.

The only thing that erases everything is **Reset**. Individual routines go with
**Delete last Routine**.

---

## 8. If something seems wrong

**The buttons no longer react while recording.**
All eleven values are recorded. Tap **Finish Routine**.

**A value in the table is white instead of coloured.**
It is a number the buttons do not produce, e.g. a typo — 7 instead of 5. Tap the
cell and correct it.

**The library is empty although routines were recorded.**
Either **Reset** was used, or you are on a different device or in a different
browser than before. Routines do not travel between devices.

**I tapped the wrong value and it is already recorded.**
Finish the routine as normal, then correct the cell in the library (section 5).
